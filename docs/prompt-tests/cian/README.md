# Тестовые входные данные для промпта ЦИАН

В каждом файле есть только данные, доступные модели: `params` и `photos`.
Инструкцию ЦИАН и лимиты передавайте отдельно, чтобы оба набора проверяли одну
и ту же версию промпта.

## 01 — продажа квартиры, полная карточка

Проверяет, что текст использует подтверждённые преимущества и структурирует
полные данные: цену, параметры квартиры, дом, метро, условия продажи и детали
из `extra`. В тексте нельзя утверждать, что квартира является апартаментами,
пентхаусом или имеет особенности, которых нет в данных.

## 02 — долгосрочная аренда, неполная карточка

Проверяет, что текст не маскирует отсутствие данных общими формулировками и не
додумывает метро, район, тип дома, площадь кухни, наличие стиральной машины или
условия, которых нет в `params`. При этом в нём должны корректно отразиться
цена, залог, комиссия, коммунальные платежи, мебель, холодильник и ограничения
на проживание с животными.
