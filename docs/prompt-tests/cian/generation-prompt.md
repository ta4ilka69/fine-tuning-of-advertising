# Промпт генерации объявления для ЦИАН

Перед вызовом замените `{{title_limit}}` и `{{text_limit}}` на числовые
значения версии канала. В `{{params_json}}` и `{{photos_json}}` передаются
данные из одного из тестовых наборов или из реального объявления.

```text
Ты готовишь объявление о недвижимости для публикации на ЦИАН.

Входные данные:
- `params` — структурированные сведения об объекте и сделке;
- `photos` — описания фотографий;
- `title_limit` — максимальная длина заголовка в символах, включая пробелы:
  {{title_limit}};
- `text_limit` — максимальная длина текста в символах, включая пробелы:
  {{text_limit}}.

Подготовь один заголовок и один текст объявления.

Используй только факты из `params` и `photos`. Отсутствующее поле означает,
что сведения неизвестны. Не делай выводов по косвенным признакам и не добавляй
характеристики, преимущества, инфраструктуру или условия, которых нет во
входных данных. Сведения из фотографий используй только для описания того, что
на них явно указано.

Заголовок должен кратко передавать тип объекта, ключевой параметр и наиболее
заметное подтверждённое преимущество. Для квартиры используй число комнат и
общую площадь, если они переданы. Добавляй метро, район или особенность объекта
только если это подтверждено входными данными и помещается в лимит. Не используй
капслок, эмодзи, хештеги, контакты, ссылки, оценочные эпитеты и восклицательные
знаки.

Текст пиши в нейтральном информационном тоне, подробно и естественно. Начни с
одного-двух предложений о ключевых параметрах и главном подтверждённом
преимуществе объекта. Затем последовательно раскрой:
1. параметры, состояние и оснащение объекта;
2. условия сделки или аренды;
3. дом, расположение, транспорт и окружение.

Включай только разделы, для которых есть сведения. Не перечисляй поля JSON
подряд: объединяй факты в связные короткие абзацы. Указывай цену и все
существенные условия сделки. Для аренды явно отражай залог, комиссию,
предоплату, состав коммунальных платежей и ограничения на проживание, если они
переданы. Не выдавай отсутствие удобства за преимущество; отрицательные
характеристики упоминай только когда их сокрытие исказит существенные условия
аренды или сделки.

В тексте обязательно укажи переданные цену, тип сделки, тип объекта, общую
площадь и полный адрес; для квартиры — число комнат. Для аренды обязательны
также залог и комиссия. Если переданы другие существенные условия сделки,
например возможность ипотеки, свободная продажа или отдельная оплата счётчиков,
отрази их точно.

Описание должно быть уникальным и конкретным. Используй поисковые формулировки
только когда они подтверждены данными: например, «7 минут пешком до метро»,
«кирпичный дом», «евроремонт» или «возможна ипотека». Не повторяй ключевые
слова ради выдачи. Не начинай текст шаблонными фразами вроде «продаётся уютная
квартира в центре города». Не включай в заголовок или текст контакты, ссылки,
призывы написать или позвонить.

До ответа посчитай символы, включая пробелы. Длина `title` не должна превышать
{{title_limit}}, длина `text` — {{text_limit}}. Если текст не помещается,
сократи второстепенные детали, сохранив цену, важные условия сделки и
грамматически законченные фразы.

Верни только JSON без Markdown и пояснений:
{
  "title": "...",
  "text": "..."
}

Данные объекта:
{{params_json}}

Фотографии:
{{photos_json}}
```
